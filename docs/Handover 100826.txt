New Discovery and Next Implementation



Equalled Records - current system assumes:
One category
    ↓
One current record

where reality is:
One category
    ↓
Multiple current records



Example:

Open F High Jump
Vanessa Ward CUT 1.98m Perth 12/02/1989
Alison Inverarity UWA 1.98m Germany 17/07/1994


Future Design

Athletics West staff with NOT determine:

New Record
Equalled Record

System should determine automatically

Current status:

SQL table already contains performance_numeric which can support this, although performance_numeric is currently unpopulated.
