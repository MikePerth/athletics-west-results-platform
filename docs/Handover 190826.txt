
 Athletics West Records Platform - Project Handover Document
Project Overview

This document provides a comprehensive handover of the Athletics West Records Platform as at the current development milestone.

The platform consists of:

Backend API (FastAPI + PostgreSQL)
Admin UI (React)
Public Website (React)
PostgreSQL Database

Purpose:

Manage Athletics West records.
Support Senior and Junior record schemes.
Maintain record progression/history.
Manage athletes and relay teams.
Support public athlete profiles.
Support record verification and auditing.
Display and maintain wind-assisted performances.
