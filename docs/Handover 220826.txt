Original Bug (Resolved)


Symptom

Kavroop had an impossible result:

Root Cause

Parser was not recognising Qualification event headers.

Roster PDF contains:

U13 - 18 Javelin Throw · Women & Girls · Multiple · Qualification · q: 8
1 Kavroop Bhangu (2013)AUS U14 Joondalup Athletics Centre 42.67 q PB


Because Qualification headers weren't being recognised, the parser remained in:
current_event = {
    "event": "100m"
}

and attached 42.67 to the 100m event



Result

Now correctly stored as:

Round = Qualification
Performance = 42.67
